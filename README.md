# 💰 Personal Finance Tracker

A sophisticated, interactive web application designed to help users manage their financial health. Built with **React 18**, this tracker features dynamic data visualization and a modern UI/UX powered by **Tailwind CSS** and **Framer Motion**.

🔗 **Live Demo:** [https://gracearop.github.io/finance-tracker](https://gracearop.github.io/finance-tracker)

## ✨ Features

- **Dashboard Overview:** At-a-glance summary of total income, expenses, and current balance.
- **Dynamic Charts:** Visual spending analysis using **ApexCharts** and **Recharts** for clear category breakdown.
- **Smooth Interaction:** Fluid UI transitions and animations powered by **Framer Motion**.
- **Transaction History:** Add, track, and categorize financial entries with ease.
- **Local Persistence:** Your data is stored locally, ensuring privacy and persistence across browser sessions.
- **Responsive Design:** Fully mobile-responsive interface using **Flowbite React** and **Tailwind CSS**.

## 🛠 Tech Stack

- **Framework:** React.js (v18.3.1)
- **Styling:** Tailwind CSS & Flowbite React
- **Visualization:** ApexCharts & Recharts
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Deployment:** GitHub Pages (via gh-pages)
